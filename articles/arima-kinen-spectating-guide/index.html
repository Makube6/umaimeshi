有馬記念を競馬場で観戦するには｜2026年の日程・指定席・入場・食事のタイミング

2026年有馬記念(12月27日・中山競馬場)を現地観戦するためのガイド。指定席のネット予約、入場券、混雑と食事のタイミング、他のGⅠ当日にも使える準備をJRA公式情報をもとに解説します。

#有馬記念 #GⅠ #中山競馬場 #観戦

2026年の有馬記念(GⅠ)は12月27日(日曜)に中山競馬場・芝2,500メートルで行われます(第71回、JRA公式)。有馬記念を競馬場で観戦するために最も大切なのは、「指定席と入場券は事前にネット予約で確保する」「GⅠ当日は入場料・指定席料金が特別料金になり、当日入場券が発売されないことがある」という2点を早めに理解しておくことです。この記事では、有馬記念当日の中山競馬場で、混雑のなかでも食事と観戦の両方を楽しむための準備と当日の動き方を、JRA公式情報をもとにまとめます。他のGⅠ(日本ダービー・天皇賞(秋)・ジャパンカップなど)の現地観戦にも応用できます。

有馬記念の歴史を少しだけ

有馬記念は、日本中央競馬会第2代理事長の有馬頼寧氏の提案で1956年に創設された「中山グランプリ」が前身です。出走馬をファン投票で選ぶという当時としては画期的な仕組みで始まり、翌1957年から有馬氏の功績を称えて「有馬記念(グランプリ)」と改称されました。以来、暮れの風物詩として親しまれ、2014年からはテレビ生中継での公開枠順抽選も行われています(JRA公式「有馬記念」ページの解説より)。中山競馬場のグランプリガーデンには歴代優勝馬のプレートが並び、当日の散策スポットになります。

指定席・入場券の確保(最重要)

  1. ネット予約の会員登録を済ませる：JRAの「指定席・入場券ネット予約」はJRAカード会員か一般会員の登録が必要です。20歳未満は登録できません。JRAカード会員は先行抽選と一般抽選の両方に申し込めます。
  2. 抽選に申し込む：GⅠ当日の指定席は抽選発売が中心です。JRAは抽選・発売スケジュールを公式サイトで公開しており、GⅠ実施日は応募状況の途中経過も掲載されます。
  3. 入場券も事前予約：東京競馬場の天皇賞(秋)・ジャパンカップ当日は当日入場券が発売されず、ネット予約の入場券も入場時間帯ごとに枚数が決まっています(2026年秋、JRA公式「東京競馬開催日のご入場方法」の案内)。有馬記念も同様の運用になる可能性が高いので、指定席が取れなかった場合も入場券の予約を忘れずに。
  4. QRチケットの準備：予約した指定席・入場券は当日0時からQRチケットを表示できます。同行者分は事前に「チケット分配」しておくと、別々に来場できて入場がスムーズです(JRA公式「中山競馬開催日のご入場方法」の案内。混雑緩和のため来場前の分配が求められています)。

中山競馬場の指定席は、スタンド最上階のG-Seat、ゴール板に最も近いA-Seat、4階のV-Seat、B-Seat、一人掛けワイドのK-Seat、4席単位のボックスシート、屋外のスマートシートなど。席種の違いは中山競馬場グルメガイドにまとめています。

当日の食事のタイミング

GⅠ当日は入場から最終レースまで売店の行列が途切れません。食事を確保するためのコツは「早く・分けて・前倒し」です。

  • 入場直後に一品目：入場時間帯が指定されている場合、入場したらまずフードコートや売店へ。開門直後が一日で最も空いています。
  • 昼食は11時前：通常開催日より1時間早く動くイメージです。
  • メインレースの2時間前までに食事を終える：有馬記念の発走前はパドック・スタンド・売店のどこも動きにくくなります。この時間は観戦に集中しましょう。
  • 飲み物は多めに：場内にはコンビニエンスストア(スタンド内に1店舗)がありますが、混雑時は補充に時間がかかります。
  • 馬場内の活用：有馬記念前日など特定日のみオープンする「馬場内UMAMI PARK」はイベント会場として使われます。利用可否は当日の案内で確認を。

GⅠ当日に場内で出走馬の情報を一から調べるのは現実的ではありません。前日までに予想を確認し、買い目を決めておけば、当日は食事と観戦に集中できます。

当日の動き方(モデルスケジュール)

  1. 指定された入場時間に合わせて到着：JR船橋法典駅からは専用地下道で徒歩約10分。駅の臨時改札口は8時00分から開設されます。
  2. 入場後すぐに食事を確保し、指定席がある場合は席に荷物を置いて場内を把握。
  3. 午前中のレースはスタンドで雰囲気に慣れる時間に。
  4. 午後早めにパドックへ。有馬記念のパドックは非常に混むので、1つ前のレースのパドックで位置取りをしておくと見やすくなります。
  5. 有馬記念を観戦。
  6. 帰路は時間差で：レース直後の船橋法典駅は大変混雑します。専用地下道の通行は17時20分までなので、グランプリガーデンなどで少し時間をずらすか、西船橋駅・東中山駅方面のバスも検討を。

他のGⅠにも共通する準備チェックリスト

  • ネット予約の会員登録(20歳未満不可)と抽選申込みの締切確認
  • 入場券の事前予約(当日入場券が発売されない日がある)
  • QRチケットの事前表示とチケット分配
  • 現金の用意(場内にATMなし)
  • 防寒・防風対策(12月の屋外席は冷えます。雨天でも座席変更・返金はありません)
  • モバイルバッテリー(屋外のスマートシートにはコンセントがありません)
  • 前日までの予想確認と買い目の決定

2026年のGⅠ日程(JRA公式)では、日本ダービーが5月31日、天皇賞(秋)が11月1日、ジャパンカップが11月29日(いずれも東京競馬場)、宝塚記念が6月14日(阪神競馬場)です。東京競馬場でのGⅠ観戦は東京競馬場グルメガイド、中山競馬場の店舗情報もあわせてご覧ください。

まとめ

有馬記念の現地観戦は、指定席・入場券のネット予約が全ての出発点です。当日は「入場直後に食事を確保」「昼食は11時前」「メインレース2時間前までに食事を終える」の3つを守るだけで、混雑のなかでも落ち着いて一日を楽しめます。

そして、年末の大一番を気持ちよく見届けるために、予想は前日までに済ませておきましょう。
